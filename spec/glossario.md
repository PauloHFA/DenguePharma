# Glossário

| Termo | Definição |
| --- | --- |
| Documento | Publicação, registro de ensaio ou documento institucional, com identidade própria. |
| Versão documental | Conteúdo de uma fonte em um instante, com hash e proveniência preservados. |
| Estudo | Investigação identificada por `study_id`, que pode ter vários relatos. |
| Família | Documentos relacionados que devem permanecer juntos em partições e reamostragem. |
| Campo revisado | Valor ou ausência individualmente aprovado/publicado pelo fluxo de curadoria. |
| Corpus coletado | Registros recuperados; a elegibilidade pode estar pendente. |
| Bronze | Bytes de entrada preservados e privados. Nesta fase, são snapshots analíticos legados, não cópias retroativas de respostas HTTP. |
| Prata | Documentos, versões, identificadores, vínculos e campos científicos estruturados, sem promover pendências. |
| Ouro / mart | Conjunto analítico reconstruível. `mart_panorama` conta estudos revisados; `corpus_*` diagnostica documentos/registros. |
| Run | Preparação identificada por entrada, código, dependências e configuração. |
| Publicação de run | Disponibilização explícita dos derivados públicos; não é aprovação científica de todos os registros. |
| Completude | Valores presentes divididos por unidades aplicáveis, com estados/denominadores explícitos. Não é risco de viés. |
| Piloto operacional | Os 50 registros previamente coletados para testar o processamento. |
| Piloto metodológico | Os 20 registros previstos no novo PDF para calibrar seleção/anotação; ainda pendente. |
| Referência adjudicada | Anotação independente resolvida por especialista para avaliar extração; ainda inexistente nesta fase. |
